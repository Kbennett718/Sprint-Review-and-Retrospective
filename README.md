# Sprint-Review-and-Retrospective
How do I interpret user needs and implement them into a program? How does creating “user stories” help with this?

I think understadning what the user needs is one of the most important parts when developing a program. User stories help break down those needs into smaller tasks that are easier to understand and complete. They also help developers focus on what the user wants and why certain features are important. This mkaes it easier to create a program that meets users expectations.

How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

When developing programs, I think it is important to stay organized, plan ahead, and be open to making changes along the way. One thing I learned from agile is that development does not always go exactly as planned, so being able to be flexible throughout is important. In the future, I would like to use Scrum meetings, sprint planning, and regular testing to help keep future projects organized and be able to catch problems early.

What does it mean to be a good team member in software development?

Being a good team member means communicating, stay being responsible for your work, and being wiling to help others. Software development involves different roles working together toward the same goal. I think it is important for everyone t share their progress, ask questions when needed, and respect each other s ideas. Good teamwork helps projects run more smoothly and makes it easier to solve problems.
